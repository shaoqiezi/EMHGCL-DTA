# EMHGCL-DTA
This is the Pytorch implementation for our paper: Enhancing Cross-scale Feature Mutual Information via Heterogeneous Graph Contrastive Learning for Drug-Target Binding Affinity Prediction. 

# Dependency
    python 3.9.12
    numpy 1.21.5
    torch 1.11.0
    torch-geometric 2.0.4
    rdkit 2022.03.2
    esm-2 2.0.0


# Running
    python inference.py --cuda 0
